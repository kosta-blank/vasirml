# Provenance

Derived from [Vasir](https://github.com/erikhazzard/vasir), copyright (c) 2026 Erik Hazzard, MIT. The original [LICENSE](LICENSE) is preserved. The derived source repository is [kosta-blank/vasirml](https://github.com/kosta-blank/vasirml); the upstream link records origin rather than the current active catalog.

The source inventory contains 66 top-level skills and one nested whitepaper skill. The existing reviewed set remains 38 skills. Its selected sources and imports received 39 completed reviews, including the custom project planner; consolidating two frontend skills into one produced those 38 reviewed skills. The 29 restored source imports are active and pending review. The 38 reviewed skills retain the accepted bytes from the reviewed portable export, and original skill attribution is retained across the catalog. Directory and CLI identifiers are canonicalized by replacing underscore runs with hyphens and collapsing repeated separators; original source IDs remain provenance and are not CLI aliases.

The public [review evidence guide](docs/review/README.md) and [change tracker](docs/review/change-tracker.json) record review history and checked-in hashes for the reviewed set. Recommendation tiers are separate from the `base`, `frontend`, and `gamedev` installation groups. The external release build manifest remains local historical evidence of source and transformation hashes.

The [gamedev import record](registry/gamedev-imports.json) records original IDs, legacy frontmatter, original and transformed file hashes, and import operations for all 29 restored skills. Equivalent `tools` fields become `allowed-tools`; host-specific model pins are removed from frontmatter. Canonical skill references and four references to existing filenames are corrected. The nested MMO whitepaper is available as a top-level skill and remains included as a genre-routing reference. Six game-QA reference documents are absent from the supplied source and remain an explicit content limitation.

The CLI, AGENTS/CLAUDE generation, persistent model routing, documentation, tests, and development workflows retain the upstream implementation plus the derived repository changes. Historical model-routing evidence is preserved in [the implementation work spec](docs/work/agents/project-model-routing/work-spec.md); its verification describes the earlier source snapshot, not the current release checks.

The private package `vasir-slim` version `0.1.0-slim.2` is distributed by packed archive. Its unchanged production dependency, `cli-spinners` 3.4.0, is bundled with its own MIT license. Named installation groups select catalog members without altering accepted skill content.
