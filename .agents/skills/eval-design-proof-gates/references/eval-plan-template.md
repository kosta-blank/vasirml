# Eval Plan Template

The [Template section of SKILL.md](../SKILL.md#template) owns both `eval-plan.md` formats. Follow [Plan Format](../SKILL.md#plan-format): Full Plan is the default; Compact Plan requires an explicit user request and an eligible workflow with an existing instrument. Use the selected format's structure and the shared proof requirements, state names, and evidence rules. Full plans include gate cards, orchestration when required, and missing-harness specs; compact plans group checks into Outcome, Method, Evidence, and Limits.

Use the repository's established eval-plan location, or `docs/work/<semantic-folders>/<feature-slug>/eval-plan.md` when none is established. Replace placeholders with discovered repository facts, explicit assumptions, or blockers. Preserve existing gate IDs when updating a plan.

For concrete gate detail, read [gold-standard-proof-gate-examples.md](gold-standard-proof-gate-examples.md). For applicable browser, game/mobile, and replay/restore requirements, read [domain-proof-guidance.md](domain-proof-guidance.md).
